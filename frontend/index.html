Responsible interpretation

Important limitations of model explanations.

How to read these values: Higher mean absolute SHAP values indicate greater average influence on model output in the evaluated sample. They do not show whether a feature raises or lowers risk, and they do not establish causation.
Test metrics summarize a held-out evaluation; real-world performance can differ due to population shift and data quality.
Before real use, evaluate fairness, subgroup calibration, data protection, drift, governance, and applicable regulations.

These are saved development-time SHAP summaries. This UI does not calculate per-applicant SHAP values.

RESPONSIBLE AI

Use predictions with care

This project is an educational demonstration, not a production lending system. Model predictions can be inaccurate, biased, or unsuitable for a different population.

  • Do not use a prediction as the sole basis for a lending decision.
  • SHAP can help inspect feature contributions, but does not prove fairness or causality.
  • Use synthetic or non-sensitive example data in demonstrations.
  • Real-world deployment requires validation, privacy safeguards, fairness testing, monitoring, and human oversight.
